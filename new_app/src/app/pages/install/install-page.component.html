Install Topcastles

Topcastles can be installed as an app on your device. Once installed, the app shell and castle data load instantly — castle images still require a network connection.

android Android (Chrome or Edge)

  1. Open Topcastles in Chrome or Edge.
  2. Tap the three-dot menu (⋮) in the top-right corner.
  3. Tap "Add to Home screen" or "Install app".
  4. Tap Install to confirm.

On supported versions of Chrome you may also see an Install banner at the bottom of the screen — tap it to install directly.

phone_iphone iPhone / iPad (Safari)

  1. Open Topcastles in Safari.
  2. Tap the Share button (the box with an arrow pointing up) at the bottom of the screen.
  3. Scroll down and tap "Add to Home Screen".
  4. Tap Add in the top-right corner.

iOS PWA support requires Safari. Installing from Chrome or Firefox on iOS is not supported by Apple.

desktop_windows Desktop (Chrome or Edge)

  1. Open Topcastles in Chrome or Edge.
  2. Look for the install icon (＋ or a screen with an arrow) in the address bar.
  3. Click it and then click Install.

The install icon only appears if you have not already installed the app. If you do not see it, you can also go to the browser menu → "Save and share" → "Install page as app".

wifi_off Offline support

After installation, the app shell and all ranked castle data are available offline. Individual castle photos are served from the network and will not load without a connection.
